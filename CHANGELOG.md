# Changelog

## 1.0.0 — 2026-11-16

- Black/gold responsive storefront, editorial homepage and reduced-motion-aware coffee animations.
- English/Arabic RTL interface and editable bilingual product/variant/add-on copy.
- Categories, independently priced sizes/custom package weights, galleries, availability and inventory.
- Signed cart, guest cash pickup/delivery, transactional pricing/stock and idempotent order snapshots.
- Protected admin studio for catalog, media, orders, website content/settings, users, reports and retention.
- CSRF, scrypt passwords, login throttling, session revocation, safe image processing and audit records.
- Versioned SQLite initialization, database/media backups and validated offline restore.
- Separate Windows setup/start/stop scripts targeting loopback port 8000 with process ownership checks.
- Automated backend and Chromium acceptance checks, actual application screenshots and source ZIP builder.
