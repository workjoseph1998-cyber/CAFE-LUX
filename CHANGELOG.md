# Changelog

## 2.0.0 — 2026-11-17

- Replaced the dark storefront with a mobile-first cream/coffee design, separate drinks and beans/ground catalogs, responsive cards and mobile bottom navigation.
- Preserved the Flask catalog, admin authentication, media uploads, pricing and external data architecture.
- Added guest delivery checkout, explicit review, idempotent pending WhatsApp orders, receiving-number routing, unknown-fee handling and manual-send instructions.
- Added delivery areas/minimums, daily hours, pauses, closures and admin-managed schedule slots.
- Added accurate statuses/history, stock deduction on confirmation, manual customer-notification links and delivered-only revenue.
- Added operator roles, category availability, contact visibility, variant-specific grind/temperature restrictions and exclusive extra groups.
- Updated Windows setup/start/stop and added diagnostics, interpreter detection, local runtime settings and secure initial-admin command.
- Applied non-destructive schema v3 migration. Kept old behavior in Git history, replaced outdated UI/docs/screenshots, and retained reusable backend and generated imagery.
- No deployment, default-branch merge, business-data deletion or changes to Cirrus Workplace.
