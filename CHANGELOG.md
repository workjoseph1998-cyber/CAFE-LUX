# Changelog

## 1.3.0 — Explore-only menu

- Remove public cart, checkout, ordering buttons and order submission access.
- Separate Drinks/Ground Coffee with clear categories, search and grouped menu sections.
- Warm light menu surfaces, larger readable type/prices and per-size/weight price previews.
- Add distinct generated espresso, iced, Turkish and hot-chocolate illustrations.
- Preserve admin/catalog management, existing accounts/data, Windows fixes and brand animations.
- Update explore-mode screenshots and tests; previous versions remain on their branches.

## 1.2.0 — Glass Menu

- Add 19 coffee-shop items in five bilingual categories once per installation.
- Preserve existing prices, stock, descriptions, availability, orders, accounts and settings.
- Homepage/catalog category navigation and prices beneath every item.
- Unconfigured prices are explicit and unpurchasable.
- Smoked-glass cards, frosted navigation, translucent panels and accessible fallbacks.
- Retain Windows fixes/schema v2; full source ZIP and updated screenshots.

## 1.1.0 — Windows deployment reliability

- Persist installation settings; default new Windows data to C:\CafeLuxData.
- Discover supported Python; recover missing pip with ensurepip.
- Numbered failures/nonzero exit codes, safe reruns and data preservation.
- Script-relative quoted paths, UTF-8 and PID-verified JSON readiness.
- Verify Windows venv launcher/interpreter ownership; serialize start/stop.
- Operator manage.py commands and first-admin CLI audit fix.
- Nested/space/Unicode installation tests and Windows Server 2022 CI matrix.
- Preserve website and schema v2; v1.0 stays on its original branch.
- Read-only comparison of supplied working ZIP; no Cirrus settings/data used.

## 1.0.0 — 2026-11-16

- Black/gold responsive storefront, editorial homepage and reduced-motion-aware coffee animations.
- English/Arabic RTL interface and editable bilingual product/variant/add-on copy.
- Categories, independently priced sizes/custom package weights, galleries, availability and inventory.
- Signed cart, guest cash pickup/delivery, transactional pricing/stock and idempotent order snapshots.
- Protected admin studio for catalog, media, orders, website content/settings, users, reports and retention.
- CSRF, scrypt passwords, login throttling, session revocation, safe image processing and audit records.
- Versioned SQLite initialization, database/media backups and validated offline restore.
- Separate Windows setup/start/stop scripts targeting loopback port 8000 with process ownership checks.
- Automated backend and Chromium acceptance checks, actual application screenshots and source ZIP builder.
